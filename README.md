# 📓 Garatujas

> *"Toda obra-prima começa com um rabisco."*

## Por que "Garatujas"?

Garatujas são os primeiros rabiscos de uma criança — traços tortos,
linhas sem forma definida, mas cheios de intenção e curiosidade.

Este repositório é exatamente isso: os meus primeiros rabiscos em
web design. Páginas simples, experimentos com layout, tentativas
com cores e tipografia — tudo aqui faz parte do aprendizado inicial,
sem pretensão de perfeição, mas com muito propósito.

## O que você vai encontrar aqui

- Primeiros projetos e experimentos com web design;
- Estudos de HTML e CSS;
- Layouts, componentes e páginas criadas do zero;
- Evolução visível — do mais básico ao menos básico.

## Status

🟡 Em andamento — ainda rabiscando.
